# computque — תרגול למבחן בחישוביות

אתר תרגול מתוך מבחני העבר של הקורס (פרופ׳ עופר אריאלי, MTA).
השאלות והפתרונות נבנו במקור מאתר הסיכום (`computsum`) בעזרת `tools/build_bank.py`. מעכשיו `bank.js` הוא המקור: תיקונים נעשים בו ישירות (גם מעמוד התפעול). בנייה מחדש מהסיכום דורסת תיקונים, ולכן דורשת `--force`.
העיצוב, החתימה, ערכות הצבע וכפתורי הדיווח נטענים מהריפו `main`.
